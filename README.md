## What I Work With

My main stack is **C# and ASP.NET Core**, where I build REST APIs and server-side applications.

- **APIs:** Designing RESTful endpoints with ASP.NET Core Web API, using DTOs, consistent error handling with `ProblemDetails`, and API documentation through Swagger / Scalar.
- **Data access:** Modeling relational databases and working with them through Entity Framework Core and LINQ on SQL Server and PostgreSQL.
- **Security:** Implementing authentication and authorization with ASP.NET Core Identity, JWT, and refresh tokens.
- **Real-time:** Adding real-time features with SignalR.
- **Code structure:** Applying SOLID, Dependency Injection, and Clean / 3-Tier Architecture so projects stay maintainable as they grow.
