## What I Work With

My main stack is **C# and ASP.NET Core**.

| Area | What I do |
|---|---|
| **APIs** | Build RESTful APIs with ASP.NET Core Web API, using DTOs, `ProblemDetails` for consistent errors, and Swagger / Scalar for documentation |
| **Data** | Model relational databases and query them with EF Core and LINQ on SQL Server and PostgreSQL |
| **Security** | Implement authentication and authorization with ASP.NET Core Identity, JWT, and refresh tokens |
| **Real-time** | Add real-time features using SignalR |
| **Structure** | Apply SOLID, Dependency Injection, and Clean / 3-Tier Architecture to keep projects maintainable |
